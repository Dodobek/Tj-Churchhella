# 🍇 Бот-магазин сухофруктов

Telegram-бот на 2 языках (русский, English) для продажи кураги, турецкой чурчхелы (сучук, 5 вкусов) и сушёного яблока (2 вида). Цена автоматически показывается в валюте выбранного языка. Есть корзина, оформление заказа с уведомлением владельцу, вопрос производителю и история заказов.

## Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Вся логика бота: меню, каталог, корзина, заказы |
| `config.py` | Токен, ID владельца, курсы валют, **каталог товаров (тексты, фото, цены)** |
| `locales.py` | Тексты интерфейса на 4 языках |
| `db.py` | Хранение языка пользователя, корзины и заказов (SQLite, файл `shop.db`) |
| `keep_alive.py` | Мини-сервер, чтобы бесплатный хостинг Render не "усыплял" бота |

## 🚀 Запуск

1. Получите токен у [@BotFather](https://t.me/BotFather) в Telegram (`/newbot`).
2. Узнайте свой chat_id — напишите в Telegram боту **@userinfobot**, он пришлёт ваш ID. Это нужно, чтобы бот присылал ВАМ уведомления о заказах и вопросах.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Задайте переменные окружения и запустите:
   ```bash
   export BOT_TOKEN="токен_от_BotFather"
   export OWNER_CHAT_ID="ваш_chat_id"
   python bot.py
   ```
5. Напишите боту `/start` в Telegram.

## 🖼 Как добавить фото товаров

В файле `config.py` у каждого товара и вкуса есть поле `"photo"`. Сейчас везде стоит `None` (фото ещё не готово) — бот в этом случае просто не прикрепляет картинку, но текст и кнопки работают нормально.

Есть два способа добавить фото:

**Вариант А — ссылка на изображение (проще всего):**
```python
"photo": "https://example.com/moe-foto-churchkhely.jpg",
```

**Вариант Б — свой файл рядом с ботом:**
1. Создайте папку `photos/` рядом с `bot.py`.
2. Положите туда файл, например `photos/churchkhela_apple.jpg`.
3. Укажите путь в конфиге:
   ```python
   "photo": "photos/churchkhela_apple.jpg",
   ```

📸 Когда пришлёте мне реальные фото товаров (чурчхелу вы уже упоминали) — просто скиньте их в чат, и я сразу впишу их в код.

## 💰 Как задать цены

В `config.py`:
- У чурчхелы уже стоит цена **80 сомони/кг** (`"price_tjs": 80`) — действует на все 5 вкусов.
- У кураги и сушёного яблока стоит `"price_tjs": None` — значит в боте это отображается как «Цена уточняется у производителя», а сумма по этим позициям не входит в итог корзины. Как определитесь с ценой — впишите число вместо `None`, например:
  ```python
  "price_tjs": 45,
  ```

## 💱 Курсы валют

Тоже в `config.py`, в словаре `CURRENCIES`. Цена всегда хранится в сомони (TJS), а для остальных языков конвертируется по курсу:

```python
CURRENCIES = {
    "ru": {"code": "RUB", "symbol": "₽", "rate_from_tjs": 8.7},
    "en": {"code": "USD", "symbol": "$", "rate_from_tjs": 0.092},
}
```

⚠️ Курсы — примерные и **не обновляются автоматически**. Раз в некоторое время проверяйте актуальный курс и подставляйте число вручную в `rate_from_tjs`.

## 🆓 Бесплатный деплой на Render

Тот же способ, что мы уже настраивали раньше:

1. Загрузите все файлы проекта в GitHub-репозиторий.
2. На [render.com](https://render.com) → **New → Web Service** → подключите репозиторий.
3. Настройки: Build Command `pip install -r requirements.txt`, Start Command `python bot.py`, Instance Type — Free.
4. В **Environment** добавьте:
   - `BOT_TOKEN` = токен бота
   - `OWNER_CHAT_ID` = ваш chat_id
5. Чтобы бот не "засыпал" — настройте бесплатный пинг на [uptimerobot.com](https://uptimerobot.com), указав URL вашего сервиса (`https://ваш-бот.onrender.com`), интервал — 5 минут.

⚠️ **Важно про базу данных на Render:** бесплатный тариф Render не сохраняет файлы между перезапусками (диск временный). Это значит, что при каждом передеплое файл `shop.db` (корзины, заказы, языки пользователей) обнулится. Для учебного/тестового запуска это некритично, но если магазин станет активным — стоит подключить постоянное хранилище (например, платный диск на Render, ~$1/мес, или внешнюю БД).

## Как всё устроено (если захотите расширять)

- **Добавить новый товар:** допишите запись в словарь `PRODUCTS` в `config.py` — по тому же образцу, что и существующие. Кнопки в каталоге появятся автоматически.
- **Добавить новый вкус/вид к существующему товару:** допишите в `"variants"` этого товара.
- **Изменить любой текст интерфейса:** ищите нужный ключ в `locales.py`.
- **Посмотреть все заказы (не только свои) как владелец:** сейчас заказы приходят вам личным сообщением при каждом оформлении — этого достаточно для начала. Если понадобится отдельная админ-панель со списком всех заказов — могу добавить команду `/admin_orders`, доступную только вам.
